# 🔬 Research

## 輔助駕駛之風險物體識別在真實世界的挑戰評估框架

**2025 – Present**

目前研究聚焦於輔助駕駛系統中的 **Risk Object Identification**，針對真實世界感知條件下演算法所面臨的挑戰進行分析。

研究主要探討：

* Real-world Perception
* Imperfect Perception
* Object Miss / Detection Failure
* Localization Error
* Scale / Shape Error
* Risk Object Identification
* Scenario-based Evaluation
* Safety Validation
* Failure Analysis
* Algorithm Improvement

透過 CARLA 等 Simulation Environment 建立測試情境，分析不同 Perception Error 對下游 Risk Identification 的影響，並探討如何建立系統化的 Evaluation Framework，以量化模型在不同感知條件與駕駛情境下的可靠性。

---

## Uncertainty-Aware Vision-based Risk Object Identification

研究 **Risk Object Identification** 在 Imperfect Perception 下的表現，並探討不確定性感知與風險預測方法。

相關研究包含：

* Conformal Risk Tube Prediction (CRTP)
* Multiple Coexisting Risks (MCR)
* RiskBench
* Perception Error Modeling
* Uncertainty Quantification
* Risk-IOU
* Temporal Risk Prediction
* Failure Mode Analysis

建立包含不同風險情境的 Simulation Dataset，並透過模型訓練與評估分析風險物件識別系統在不同 Perception Quality 下的表現。
